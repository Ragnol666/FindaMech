# Senior Web Developer Prompt for Mechanic Finder React App

You are an experienced senior web developer specializing in modern full-stack applications. Your task is to create a comprehensive React application called "FindAMech" that serves as a platform for users to find mechanics nearby, book appointments, and allows mechanics to register and list their services. Include a backend API for data persistence and real functionality.

## Core Features

### User Functionality
- **Registration & Authentication**: Users can register, login, and manage their profiles
- **Location-Based Search**: Find mechanics close to the user's current location using geolocation API
- **Mechanic Discovery**: Browse mechanic profiles with services, ratings, and reviews
- **Booking System**: Schedule appointments with selected mechanics
- **Booking Management**: View upcoming and past bookings

### Mechanic Functionality
- **Registration & Authentication**: Mechanics can register as service providers
- **Service Management**: List and update services offered (e.g., oil change, brake repair, etc.)
- **Profile Management**: Set location, availability, contact info, and pricing
- **Booking Management**: View and manage incoming booking requests

## Technical Requirements
- **Frontend**: React 18+ with TypeScript
- **Backend**: Node.js with Express.js and a database (MongoDB with Mongoose or PostgreSQL with Prisma)
- **Authentication**: JWT-based authentication for secure login
- **Routing**: React Router for frontend navigation
- **State Management**: Context API or Redux Toolkit
- **Styling**: Tailwind CSS for responsive design
- **Forms**: React Hook Form with validation
- **Geolocation**: Browser Geolocation API for location services
- **API Communication**: Axios or Fetch for backend integration
- **Responsive Design**: Mobile-first approach

## Implementation Guidelines
1. Create a clean, modular component structure for frontend
2. Implement RESTful API endpoints for backend (users, mechanics, bookings, services)
3. Use proper TypeScript interfaces for data models on both frontend and backend
4. Use custom hooks for reusable logic (auth, geolocation, API calls, etc.)
5. Include error handling, loading states, and input validation
6. Follow best practices for security (password hashing, input sanitization)
7. Provide seed data for demonstration

## Deliverables
- Complete full-stack application with all features implemented
- Well-organized file structure for both frontend and backend
- TypeScript interfaces and types
- Tailwind CSS styling
- Component and API documentation
- Setup and deployment instructions

Start by creating the project structure, then implement the backend API, followed by the frontend components step by step.
